# Impatient webinar pages

This repository publishes the numbered Impatient Health webinar landing pages.

- `webinar84` to `webinar93` use the standard panel layout.
- `webinar94` uses the fireside-chat layout.
- Shared panel content lives in `script.js` and shared panel styling lives in `style.css`.
- Pages are published through GitHub Pages and served at `www.impatient.health/webinars/webinarNN/`.

For a new standard panel page, copy the latest panel folder, add the event content to `script.js`, and commit the change to `main`.
